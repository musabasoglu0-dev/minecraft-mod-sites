    Eklenen İçerikler

    Minecraft Hata Kodu & Çökme Çözücü

    Launcher veya oyun başlangıcında karşılaşılan yaygın hata kodları ve kesin çözümleri:

    Exit Code: 1 (Eksik Yan Mod veya Java Sürüm Uyumsuzluğu)

    1) Mod Listenizde turuncu uyarı veren eksik yan mod (Fabric API, Cloth Config, Architectury API vb.) olup olmadığını kontrol edin.
    2) Minecraft 1.20.5 - 26.3 sürümleri için Java 21, 1.18 - 1.20.4 için Java 17 kurulu olmalıdır.
    3) Fabric ve Forge modlarını aynı mods klasörüne karıştırmadığınızdan emin olun.

    Exit Code: -1 (Render / Grafik Motoru Çakışması)

    OptiFine ile Sodium, Iris veya VulkanMod aynı anda yüklüyse doğrudan çökme yaratır. İndirdiğiniz modun sürüm aralığının (örn. 1.16.5 - 26.3) oynadığınız sürümle eşleştiğini doğrulayın.

    Exit Code: -805306369 (Yetersiz Bellek / Out of Memory)

    Ağır mod paketlerinde veya yüksek chunk mesafesinde (Bobby / Distant Horizons) RAM sınırına ulaşıldığında oluşur. Launcher JVM ayarlarından -Xmx4G veya -Xmx6G verin ve listeye FerriteCore ekleyin.
