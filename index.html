    Minecraft Hata Kodu Çözücü

    Oyununuz çöktüğünde Launcher ekranında çıkan yaygın hata kodları:

    Exit Code: 1 (Genel Mod / Java Çakışması)

    1) Eksik yan mod (Fabric API vb.) olup olmadığını kontrol edin.
    2) Modern 26.3 sürümleri için Java 21 kurulu olmalıdır.
    3) Fabric ve Forge modlarını aynı klasöre karıştırmadığınızdan emin olun.

    Exit Code: -1 (Oyun İçi Çökme / Render Hatası)

    OptiFine ile Sodium aynı anda yüklüyse çakışma yaratır. Sürümünüzle mod sürümünün eşleştiğini kontrol edin.
