    Minecraft Hata Kodu Çözücü

    Oyununuz çöktüğünde Launcher ekranında çıkan hata kodunu seçin:

    Exit Code: 1 (Genel Mod / Java Çakışması)

    1) Eksik yan mod (örneğin Fabric API, Cloth Config veya Architectury API) olup olmadığını kontrol edin.
    2) Minecraft 1.20.5+ sürümleri için Java 21, 1.18-1.20.4 için Java 17 kurulu olmalıdır.
    3) Fabric ve Forge modlarını aynı mods klasörüne karıştırmadığınızdan emin olun.

    Exit Code: -1 (Oyun İçi Çökme / Render Hatası)

    1) OptiFine ile Sodium / Iris aynı anda yüklüyse OptiFine'ı kaldırın.
    2) Oyun sürümünüzle mod sürümünün (örneğin 1.20.1 modu 1.21'de çalışmaz) birebir eşleştiğini doğrulayın.

    GLFW Error 65542 (OpenGL / Ekran Kartı Hatası)

    Ekran kartı sürücünüz (NVIDIA, AMD veya Intel) güncel değildir. Ekran kartı sürücünüzü resmi sitesinden güncelleyin ve bilgisayarı yeniden başlatın.

    OutOfMemoryError (Yetersiz RAM Hatası)

    Launcher > Yüklemeler > Düzenle > Daha Fazla Seçenek kısmından -Xmx2G değerini bilgisayarınızın RAM kapasitesine göre -Xmx4G veya -Xmx6G yapın ve FerriteCore modunu ekleyin.
